# Changing Habits Around Food — PBL 23 field trip survey

A narrated, video-style data presentation of a survey of **89 students** about busy lives, eating on the go, snacks, and the gap between knowing and doing.

**▶ Watch:** https://korenkov-shared.github.io/food-habits-survey/

Controls: `Space` play/pause · `←` `→` previous/next chapter · `F` fullscreen · `C` captions · `V` voice narration.

## Key findings
- Average busyness **7.4/10**; self-rated healthy habits only **5.6/10**.
- Eating "on the go" vs healthy habits: **r = −0.72** — the strongest pattern in the data.
- **70%** want to improve their eating; lack of time is the #1 barrier.
- **79%** love salty snacks; **19%** think that at their age they don't need to worry about health.

`data.js` contains only aggregated, anonymous results.
